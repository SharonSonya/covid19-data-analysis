## Project Overview

This project analyzes global COVID-19 data to explore the impact of the pandemic across countries, continents, and vaccination progress.

The analysis focuses on identifying countries with the highest reported cases, understanding global case distribution, and exploring vaccination patterns using SQL for data preparation and Tableau for visualization.

## Tools Used

- SQL (MySQL)
- Tableau

## Dataset

**Source:** Our World in Data - COVID-19 Dataset

The dataset contains:
- Total cases
- New cases
- Total deaths
- Vaccination data
- Population
- Country and continent information

## Key Insights

- COVID-19 affected 262 countries and territories.
- The United States, China, and India recorded the highest total case counts.
- Vaccination coverage varied significantly across countries.
- The dashboard combines KPIs, a global map, and Top 10 rankings to highlight the pandemic's global impact.

## Project Workflow

### Data Preparation (SQL)
- Imported the dataset into MySQL
- Cleaned and validated the data
- Removed aggregated records
- Prepared tables for visualization

### Dashboard Development (Tableau)
- KPI cards
- Global COVID-19 Cases Map
- Top 10 Countries by Total COVID-19 Cases
- Top 10 Countries by Fully Vaccinated Population
